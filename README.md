# Tushar Baidya Portfolio

## Files
- index.html — page structure and sections
- style.css — responsive styling
- script.js — mobile menu, active navigation, year, and contact-form interaction

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize
1. Replace the email and social links in `index.html`.
2. Replace project names, descriptions and GitHub/demo URLs.
3. Replace the TB avatar with a real profile photo if desired.
4. Connect the contact form to Formspree, EmailJS, or your own backend for real submissions.
